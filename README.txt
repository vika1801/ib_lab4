ЛАБОРАТОРНАЯ РАБОТА №4 — УРОВНИ ЗАЩИЩЁННОСТИ ИСПДн

Запуск из корневого каталога проекта:
  python программы/главный_симулятор.py


Команды интерфейса: все; система <номер>; сценарий <номер>; сценарий импорт; выход.
Выполнение симулятора автоматически обновляет текстовые документы в папках документы/ и отчёты/.

Схема связей модулей:
  данные (организация, системы, матрица, каталог мер, оборудование, СЗИ, сценарии)
      ↓
  проверка_исходных_данных → расчёт_уз → подбор_мер → проверка_оборудования
      ↓                                              ↓
  формирование документов ← аудит_соответствия ←──────────┘
      ↓
  документы/ и отчёты/

Все данные в проекте вымышленные. Учебная матрица уровней реализована как прозрачное правило,
поскольку численные ячейки матрицы из лекции в приложенном методическом файле не приведены.
Перед использованием в реальной организации необходимо проверить нормативные требования и редакции.
